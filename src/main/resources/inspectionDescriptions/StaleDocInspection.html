Reports documentation blocks (Javadoc, KDoc, docstrings, JSDoc) that may be outdated.

The inspection uses git history to compare when the documentation was last modified versus when the associated code was last changed. If the code has been modified multiple times since the documentation was updated, the doc block is marked as stale.

Freshness Levels

  • Fresh (80–100) — documentation is up to date
  • Aging (50–79) — documentation may need review
  • Stale (20–49) — documentation is likely outdated
  • Rotten (0–19) — documentation is severely outdated

Configure thresholds in Settings → Tools → Docstring Freshness Monitor.
